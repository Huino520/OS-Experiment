# OS-Experiment
这里整理了实验中使用到的基础环境和完成的8个实验，经过测试可以直接运行，下面将详细介绍目录结构、测试方法和理想结果。

目录结构：

oslab --基础运行环境，经典的linux0.11环境代码，包括常用的脚本和完整的代码，没有经过编译。

exp1 --实验1 操作系统的引导

exp2 --实验2 系统调用，包括两步实验step1和2的实验代码

exp5 --实验5 地址映射与共享，完成主要依据参考代码，实现和实验包提示不同（如没有使用休眠队列）

exp8 --实验8 在Linux0.11上实现交换分区和全局页面置换，部分页面置换情况没处理好（集中于用户态的页面置换）
